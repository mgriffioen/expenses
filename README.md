# Expenses

An iPhone app for tracking expenses grouped by trip/event, with receipt
scanning and on-device text extraction.

- **UI:** SwiftUI
- **Storage:** SwiftData, local to the device (no backend, no account)
- **Receipt capture:** VisionKit's `VNDocumentCameraViewController` (auto
  crop/perspective-correct)
- **Receipt OCR:** Vision's `VNRecognizeTextRequest`, fully on-device — no
  cloud API, no network calls, receipts never leave the phone

## What's in this repo right now

Just Swift source files under `ExpensesApp/` — there's no `.xcodeproj` yet.
Xcode project files are generated by Xcode itself and this repo was set up
outside of macOS, so the project needs to be created once, on your Mac, by
you. It only takes a few minutes.

```
ExpensesApp/
  ExpensesApp.swift        # app entry point
  Models/
    Trip.swift              # a trip/event; owns a list of expenses
    Expense.swift            # a single expense, optionally with a receipt photo
    ExpenseCategory.swift
  Services/
    ReceiptImageStore.swift  # saves/loads receipt photos to disk
    ReceiptScannerView.swift # wraps the VisionKit document camera
    ReceiptTextExtractor.swift # OCR + heuristics to guess total/merchant/date
  Views/
    TripListView.swift
    AddTripView.swift
    TripDetailView.swift
    ExpenseRowView.swift
    AddExpenseView.swift     # manual entry + "Scan Receipt" flow
```

## One-time setup on your Mac

1. **Install Xcode** from the Mac App Store (free). First launch will
   install additional components — let that finish.
2. **Create the project:** File → New → Project → iOS → App.
   - Product Name: `Expenses`
   - Interface: **SwiftUI**
   - Storage: **SwiftData** (leave "Host in CloudKit" unchecked for now)
   - Save it anywhere temporarily, e.g. your Desktop.
3. **Delete the template's default files** in the project navigator:
   `ContentView.swift` and `Item.swift` (move to trash). Keep the
   auto-generated `ExpensesApp.swift` for now — you'll replace its contents.
4. **Copy this repo's files in:** in Finder, drag the `Models`, `Services`,
   and `Views` folders from this repo's `ExpensesApp/` directory into the
   Xcode project navigator (drop them at the top level, next to
   `ExpensesApp.swift`). When prompted, choose **"Copy items if needed"**
   and make sure the **Expenses target checkbox is checked**. Then open
   this repo's `ExpensesApp.swift` and paste its contents over Xcode's
   generated one.
5. **Add the camera permission string:** select the project in the
   navigator → the `Expenses` target → **Info** tab → add a row:
   - Key: `Privacy - Camera Usage Description`
   - Value: `Used to scan and photograph receipts.`
6. **Build and run:** pick a Simulator (e.g. iPhone 16) and press
   Cmd+R. You should be able to add a trip and add an expense manually.
   The Simulator has no camera, so receipt scanning itself needs a real
   device (next step) — everything else works in the Simulator.
7. **Run on your iPhone:**
   - Plug your iPhone into your Mac.
   - In Xcode → Settings → Accounts, sign in with your Apple ID (free is
     fine for now).
   - Select the project → target → **Signing & Capabilities** → set your
     Team to your personal team.
   - Select your iPhone as the run destination and press Cmd+R.
   - First run: on the iPhone, go to Settings → General → VPN & Device
     Management and trust your developer certificate.
   - Apps signed with a free Apple ID need re-signing (just re-run from
     Xcode) about once a week.

Once that's working, commit the generated `Expenses.xcodeproj` and any
Xcode-created files to this repo so the project builds straight from a
`git clone` next time.

## Current feature set

- Create trips/events, each with its own running total
- Add expenses manually (merchant, amount, date, category, notes)
- Scan a receipt with the camera; the photo is saved and OCR pre-fills
  the amount, merchant, and date (best-effort — always editable before
  saving)
- Delete trips/expenses (removes the associated receipt image from disk)

## Natural next steps
